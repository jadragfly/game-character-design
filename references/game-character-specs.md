# 游戏角色动画基础规格

## 平台游戏角色规格

本规格定义了适用于超级马里奥、银河战士、蔚蓝等平台游戏的主角动画要求。

---

## 角色比例规格

| 类型 | 头身比 | 说明 |
|------|--------|------|
| chibi/可爱风 | 2-3头身 | 头大身小，适合休闲游戏 |
| 标准平台风 | 3-4头身 | 经典马里奥风格，平衡可爱与帅气 |
| 写实像素风 | 4-6头身 | 角色更加修长 |

---

## 帧动画规格

### Atlas 规格（可配置）

**标准规格（默认）**：
- Atlas 尺寸：1536 x 1872 px
- 网格：8 列 x 9 行
- 单帧尺寸：192 x 208 px

**精简规格（可选）**：
- Atlas 尺寸：1024 x 1024 px
- 网格：8 列 x 8 行
- 单帧尺寸：128 x 128 px

### 帧率建议

| 动作类型 | 帧数 | 播放帧率 | 时长 |
|---------|------|---------|------|
| idle | 4 | 4-8 FPS | 0.5-1秒 |
| walk | 6-8 | 10-12 FPS | 0.5-0.8秒 |
| jump | 4-6 | 10-12 FPS | 0.3-0.5秒 |
| attack | 4-6 | 12-15 FPS | 0.3-0.5秒 |

---

## 角色朝向规则

游戏中角色朝向必须明确：

- **walk-left**：角色完全朝左看，左腿在前
- **walk-right**：角色完全朝右看，右腿在前
- **jump**：保持当前朝向，上升时手臂动作与朝向协调
- **fall**：保持当前朝向，下落时双臂张开

---

## 通用动作模板

### 行走循环（walk-left / walk-right）

```
方向：[LEFT/RIGHT]
帧数：6-8帧
节奏：着地-支撑-离地-摆动-着地（循环）

Frame 0: 后腿着地，身体微倾
Frame 1: 重心转移，身体下沉
Frame 2: 前腿着地，抬腿最高点
Frame 3: 后腿抬起，准备前摆
Frame 4: 后腿前摆超过前腿
Frame 5: 后腿接近前腿位置
Frame 6: 后腿着地（前腿抬起）
Frame 7: 回到 Frame 1 状态，循环
```

### 跳跃（jump-up / jump-down 分离）

```
jump-up（起跳到最高点）：
Frame 0: 下蹲蓄力
Frame 1: 蹬地起跳，双腿伸展
Frame 2: 身体上升，手臂上摆
Frame 3: 到达最高点，身体蜷缩

jump-down（最高点到落地）：
Frame 0: 开始下落，伸展
Frame 1: 继续下落，双臂张开
Frame 2: 接近地面，收腿准备
Frame 3: 脚触地，膝盖弯曲
```

### 攻击（attack）

```
方向：[LEFT/RIGHT]
武器类型：[拳/剑/枪/特殊]
帧数：4-6帧

Frame 0: 预备姿态，手臂收回
Frame 1: 蓄力/举拳
Frame 2: 攻击动作完成
Frame 3: 收招/复位
```

## 动画衔接规则

游戏动画必须考虑状态切换的平滑性：

### 站立 → 行走
- idle 最后一帧与 walk 第一帧保持相同高度

### 行走 → 跳跃
- walk 中间帧可以作为 jump 的起跳帧

### 跳跃 → 落地
- 落地帧后应快速回到 idle

### 下蹲 → 站立
- 可直接衔接，1-2帧过渡

---

## Chroma Key 规则

所有帧必须使用 `#00FF00` 纯绿色作为背景色。

**禁止出现绿色系的情况**：
- 角色本体
- 角色身上的配饰
- 角色高光或阴影
- 任何道具

---

## 禁止出现的特效

### 绝对禁止
- 速度线、动作条
- 残影、模糊
- 地面阴影
- 离体粒子/星星
- 武器拖尾（攻击除外）
- 角色以外的物体

### 攻击动作允许的特效
- 武器本身的动画（如剑光）
- 命中瞬间的简单特效（如冲击波）
- 子弹/炮弹（射击类动作）

---

## 帧同步要求

所有动作必须严格同步：
- 手臂与腿部动作必须协调
- 呼吸循环必须在 idle 中完美循环
- 行走周期的着地帧必须一致

---

## 方向性动画规则

### 左向动画（-left）
- 角色必须完全朝左
- 武器/道具在左侧（如左手持剑）
- 攻击挥动从左向右

### 右向动画（-right）
- 角色必须完全朝右
- 武器/道具在右侧（如右手持剑）
- 攻击挥动从右向左


---

## 验收标准

1. **帧数正确**：每个动作必须有完整的指定帧数
2. **循环完美**：idle 和 walk 必须能无缝循环
3. **方向正确**：左/右动画必须明确区分
4. **无错误颜色**：无 chroma key 绿色渗入角色
5. **姿态清晰**：每帧动作意图明确，无模糊帧
6. **高度一致**：同动作帧的角色高度应该一致
